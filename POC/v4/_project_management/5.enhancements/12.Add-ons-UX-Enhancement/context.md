# Context - Add-ons UX Enhancement

**Date:** 2026-03-24

## Background
The Add-ons section within the Recommendation Panel lists supplemental tests recommended for the patient. While already collapsible, the UI needed more explicit hints indicating that users can expand/collapse the section, and that clicking individual add-ons reveals the AI reasoning.

## Objective
Improve the UX for the Add-ons section by adding clearer call-to-action text for expanding/collapsing the group and revealing the AI reasoning for each item.
