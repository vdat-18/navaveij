# Context: Screening & Vaccination Gap Status — Hover-reveal Redesign

## 1. Request
The Screening & Vaccination Gap Status section displayed all information (status, history, notes) by default, making each card tall and consuming too much vertical space. The request was to match the UI pattern of the Strategic Add-ons section: compact by default, details revealed on hover.

## 2. Requirements
- Compact default view: show only the test/vaccine name and a priority dot.
- Reveal full detail (Status, History, Notes) on mouse hover.
- Color-coded frames per priority (red/orange/yellow/green) replacing text labels.
- Smooth, performant reveal animation using CSS transitions only.
- Visual consistency with the rest of the Dashboard (same design language).
