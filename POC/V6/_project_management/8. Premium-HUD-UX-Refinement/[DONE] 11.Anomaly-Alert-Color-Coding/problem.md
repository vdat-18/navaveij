# Problem — Anomaly Alert Color Coding

**Date:** 2026-03-24

---

## Current State
- Severity was indicated by text labels (HIGH, MEDIUM, LOW) at the top right of cards.
- All cards had identical gray borders and white backgrounds.

## Pain Points
- Text-based status requires reading, increasing cognitive load.
- Lack of immediate visual distinction between a critical alert and a low-priority one.
- Inconsistent with the new "Sales-Aggressive" high-density design language used elsewhere.
