# Problem — Email this Report

**Date:** 2026-03-27
**Complaint Source:** Client feature request

---

## Problem Statement

The Navaveij clinical recommendation dashboard generates a rich, multi-section health checkup report — including risk level, recommended package, add-ons, AI reasoning, and communication script — but there is currently no way for a physician or nurse to share this report with the patient or any external stakeholder.

The only way to view the report is on-screen, inside the main dashboard. There is no export, no print-friendly view, and no email delivery mechanism.

This creates a workflow gap: physicians need to relay recommendations verbally or retype them into another system. This introduces transcription risk and reduces the perceived value of the AI recommendation output.

---

## Specific Gaps

### Gap 1 — No "Email this Report" action on the recommendation panel

The `RecommendationPanel` component (`frontend/src/components/dashboard/RecommendationPanel.tsx`) has Approve/Reject action buttons but no mechanism to share or export the report. There is no "Email", "Print", or "Export" CTA.

### Gap 2 — No flat/print-friendly report view

The dashboard layout is designed for interactive on-screen use: it has a sidebar, a patient directory column, a recommendation panel, and a clinical drawer. There is no dedicated "report view" that flattens all sections into a linear, printable format.

A proper report view would:
- Show all recommendation sections in a single-column, top-to-bottom layout
- Be suitable for browser print-to-PDF
- Have no interactive chrome (no sidebar, no drawer, no streaming controls)

### Gap 3 — No email delivery capability

There is no mechanism to deliver the report to the patient's email address. The `Patient` type already includes an `email` field (and `phone`), but it is only used for display. No email send, no `mailto:` integration, and no backend email endpoint exist.

---

## Impact

- **Clinical workflow friction:** Physicians must manually summarise the AI recommendation when communicating with patients — defeating the purpose of the communication script generated by the AI.
- **Patient experience:** Patients receive no written record of their health recommendation or next actions.
- **Demonstration gap:** For client demos, the lack of an "Email this Report" action makes the system feel incomplete, since the recommendation dashboard is the primary deliverable.
