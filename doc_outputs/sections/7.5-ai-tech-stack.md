# 7.5 AI Tech Stack

| Component | Technology | Version | Role |
|---|---|---|---|
| Structured LLM Prompting | BAML (BoundaryML) | 0.213.0 (pinned) | Type-safe output schema enforcement for all three clinical agents; prompt bodies are supplied by the per-model YAML template registry |
| Per-Model Prompt Templates | YAML template registry (`baml_src/prompts/`) | — | Model-specific system prompt sets (GPT-4o / Claude 3.5 / Llama); active set loaded at startup by the Prompt Template Selector based on `AI_ACTIVE_CLIENT` |
| AI Orchestration | FastAPI + asyncio | ≥ 0.135.1 / Python ≥ 3.10 | Asynchronous 4-phase workflow coordination; parallel agent execution |
| Clinical Context Middleware | MCP (FastMCP) | 1.26.0 | Read-only clinical context tool server; stdio transport |
| LLM Providers | OpenAI / Anthropic / Ollama / OpenRouter | — | Multi-provider support via the AI gateway fallback chain |
| LLM Client SDK | openai-py | ≥ 2.26.0 | Unified OpenAI-compatible client for cloud and self-hosted model endpoints |
| Configuration | Pydantic + pydantic-settings | ≥ 2.0.0 / ≥ 2.13.1 | Environment-variable-driven configuration, including active model selection |
| Logging | Loguru | ≥ 0.7.2 | Structured asynchronous logging |
| Audit Storage | JSONL + SHA-256 | Python stdlib | Append-only, hash-chained immutable audit trail |
| Caching | In-memory TTL cache | — | Risk profile cache keyed on a hash of the scrubbed clinical signal set |
| ASGI Server | Uvicorn | ≥ 0.41.0 | Production asynchronous HTTP server |
