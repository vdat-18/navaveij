# 7.4.1 Explainable AI (XAI) & Confidence Scoring

Every recommendation produced by the AI pipeline includes a structured explanation and a system-computed confidence score. These are designed to support physician judgement — not replace it — by making the AI's clinical reasoning transparent and quantifiable.

### Reasoning Trace

The reasoning trace is assembled from two sources within the AI pipeline:

- **Clinical risk profile bullets** — produced by Agent 1 (`AnalyzeClinicalRisks`): a structured set of identified risk factors, severity classifications, and contraindication flags derived from the patient's clinical signals
- **Policy reasoning** — produced by Agent 2a (`MatchPolicy`): the AI's written justification for the selected tier and add-on items, including a mandatory deviation justification if the AI overrides the rule-computed preliminary tier

These two outputs are combined into the `reasoning_trace` field exposed in the API response, giving the physician a readable account of why a specific recommendation was generated.

### Confidence Score

The confidence score is computed deterministically by the system after AI inference — it is not a self-reported probability from the LLM. This design prevents the model from producing artificially high confidence values and ensures the score reflects the actual completeness of the available clinical data.

The formula:

```
confidence_score = 0.4 × signal_coverage + 0.4 × data_completeness + 0.2 × rule_agreement
```

| Component | Definition | Weight |
|---|---|---|
| `signal_coverage` | Proportion of expected clinical signals for which data was available | 40% |
| `data_completeness` | Proportion of required output fields successfully populated | 40% |
| `rule_agreement` | 1.0 if the AI-selected tier matches the deterministic rule tier; 0.0 if it deviates | 20% |

The score is expressed as a value between 0 and 1, rounded to three decimal places.

### Confidence Tiers

| Tier | Score Range | Behaviour |
|---|---|---|
| High | ≥ 0.75 | Recommendation delivered without mandatory review flag |
| Medium | 0.50 – 0.74 | Recommendation delivered; physician discretion advised |
| Low | < 0.50 | `review_required: true` set; clinical UI flags recommendation for mandatory physician review before acting |

> **Note:** Confidence tier thresholds are pending confirmation with clinical stakeholders and may be adjusted based on clinical validation results.

### Communication Script

Agent 2a and Agent 2b jointly produce a four-field patient-facing communication script that accompanies the recommendation:

| Field | Content |
|---|---|
| `health_summary` | Plain-language summary of the patient's current health status and key findings |
| `recommendation_rationale` | Explanation of why this programme tier and these add-ons were selected |
| `addon_highlights` | Concise clinical rationale for each recommended add-on item |
| `next_steps` | Actionable guidance for the patient on what to expect and how to proceed |

All XAI fields — the reasoning trace, confidence score, confidence tier, and communication script — are included in the API response and available to the clinical UI for physician display.
