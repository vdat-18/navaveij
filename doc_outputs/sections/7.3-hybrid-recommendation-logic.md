# 7.3 Hybrid Recommendation Logic

The recommendation engine uses a three-layer decision architecture that combines deterministic clinical rules with AI-driven contextual reasoning. Each layer has a fixed responsibility; the ordering ensures that AI judgement is always grounded in rule-computed clinical context and then checked by a final deterministic safety pass before any recommendation reaches a physician.

### Three-Layer Architecture

**Layer 1 — Deterministic Rule Tier (pre-AI)**
The `RuleEvaluator` processes the patient's active clinical signals and maps them to a recommendation tier using an admin-configurable rule set. Rules are evaluated in priority order; the first matching rule determines the tier. This tier serves as the anchor value passed to Layer 2.

**Layer 2 — AI-Driven Tier and Add-On Selection (Agent 2a)**
Agent 2a (`MatchPolicy`) receives both the assembled clinical context and the rule-computed preliminary tier. It selects the final tier and recommends specific add-on items. If the AI selects a tier that differs from the rule-computed anchor, it must provide a written `tier_deviation_justification` — this field is mandatory and non-nullable when a deviation occurs, ensuring that every AI override is explicitly reasoned and auditable.

**Layer 3 — Post-AI Safety Filter (deterministic)**
`SafetyRuleValidator` applies deterministic eligibility checks against the AI-recommended add-ons. Any add-on that fails a gender, age, or contraindication constraint is silently removed from the final list. Each removal is logged as a `safety_conflict_event` in the audit record. This layer cannot be overridden by AI output.

### Tier Selection Rules

Rules are evaluated in priority order. The first matching rule is applied.

| Priority | Rule ID | Tier | Match Logic | Trigger Condition |
|---|---|---|---|---|
| 1 | `PREMIUM_SEVERE_SINGLE` | Premium | Any single severe indicator | eGFR annual decline > 5 mL/min/1.73m², ASCVD 10-yr risk ≥ 20%, hypertensive crisis (SBP > 180 or DBP > 120), confirmed DM with active organ complication screening gap, or significant liver enzyme elevation (ALT > 3× ULN) with NAFLD/alcohol/high-TG indicator |
| 2 | `PREMIUM_MULTI_SIGNAL` | Premium | Cumulative signal burden | ≥ 5 of 12 moderate-to-high-risk signals simultaneously active (e.g. prediabetes, HTN, dyslipidaemia, BMI obese by Asian threshold, intermediate ASCVD, stage 2 HTN, family history of premature CAD, at-risk alcohol use, fibroscan indication, lung CT eligibility, CKD, hyperuricaemia) |
| 3 | `ADVANCED_METABOLIC_OR_CVD` | Advanced | Single metabolic/CVD signal or moderate co-occurring burden | Prediabetes or diabetes confirmation pending, intermediate ASCVD (7.5–19.9% 10-yr risk), Stage 1–2 HTN with comorbidity, LDCT eligibility, CKD (any stage), BMI ≥ 27.5 kg/m² (Asian threshold), or ≥ 2 of 14 moderate-risk indicators |
| 4 | `STANDARD_DEFAULT` | Standard | Default fallback | No elevated-risk signals present; routine annual preventive screening |

### Add-On Priority Levels

Each recommended add-on item carries a priority designation that drives the clinical UI's display order and urgency signalling.

| Priority | Clinical Indication | Examples |
|---|---|---|
| **Red** | Urgent finding — high-severity condition, active symptom, or mandatory screening gap severely overdue | Lung CT (LDCT-eligible), colonoscopy with haematochezia or first-degree CRC history, Exercise Stress Test (ASCVD ≥ 20%), FibroTouch (ALT > 3× ULN), Diabetes Screening Pro (confirmation pending) |
| **Orange** | Moderately important — standard screening overdue within accepted window or elevated risk requiring near-term attention | Cervical cancer screening (standard overdue), DEXA bone density (age ≥ 65), Carotid ultrasound (ASCVD 15–19.9%), Thyroid Pro 2 (thyroid dysfunction likely) |
| **Yellow** | Enhanced monitoring recommended — borderline or developing risk, or patient-specific surveillance | Exercise Stress Test (intermediate ASCVD), Coronary Artery Calcium scoring, Echocardiogram (DM or HTN comorbidity), 48-Hour Cardiac Patch Monitor (palpitations/syncope), Fibroscan (liver disease risk), Retinal Examination (diabetes) |
| **Green** | Shared decision-making / discretionary — USPSTF Grade C recommendation or patient-preference-dependent | PSA (age 55–69, shared decision-making per USPSTF Grade C), Spine MRI (occupational or chronic pain, discretionary) |

### Safety Validation Checks

After AI-driven add-on selection, `SafetyRuleValidator` applies four deterministic checks against each recommended item:

1. **Item validity** — item ID must exist in the current add-on library
2. **Gender constraint** — add-ons with a gender restriction are removed if the patient does not match
3. **Age bounds** — add-ons with a minimum or maximum age requirement are removed if the patient is outside the eligible range
4. **Contraindication signals** — add-ons that define contraindication signals are removed if any of those signals are active for the patient

Removed items do not appear in the final recommendation. Each removal is recorded as a `safety_conflict_event` with the item ID and violation reason, captured in the `What` dimension of the audit log.

### Fallback Chain

If AI components are unavailable, the recommendation engine degrades in steps, always producing a usable output:

| Failure Scenario | Output |
|---|---|
| Agent 1 (`AnalyzeClinicalRisks`) fails | Full rule-based recommendation; AI pipeline bypassed |
| Agent 2a (`MatchPolicy`) fails, Agent 2b succeeds | Rule-based tier applied; signal-matched add-ons used; `review_required: true` |
| Agent 2b (`WriteNarrative`) fails, Agent 2a succeeds | Narrative constructed from Agent 1 clinical summary bullets |
| Both Agent 2a and 2b fail | Full rule-based recommendation; `review_required: true` |

In degraded states where the AI tier is unavailable (Agent 1 failure, Agent 2a failure, or both Agent 2a and 2b failure), `recommendation_source` is set to `"RuleBased"` and `review_required` is set to `true`. When only Agent 2b fails, the AI-selected tier and add-ons are retained and `recommendation_source` remains `"AI"` — only the patient-facing narrative is degraded.
